# 使用离线回放与MuJoCo减少真机试错

2026-10-21。本文为可行性与实施顺序分析，尚未安装MuJoCo、创建仿真程序、运行GPU评估或启动机器人。

## 已确认的模型对照

用户反馈：第一版旧成功LoRA 30k的抓取和下降放置效果最好；第三版阶段A 3k的放置位置较准确，但不松爪。对应路径：

| 角色 | checkpoint | 训练来源 |
| --- | --- | --- |
| 首选基线 | `outputs/pi05_force_tavla_aligned_30k_resume/checkpoint-030000` | 旧101条成功示范，7维实测力矩历史 |
| 放置/释放对照 | `outputs/pi05_stage_measured_3k/checkpoint-003000` | 后采v3 30k初始化，已批准阶段窗口继续训练3k，7维实测力矩历史 |

这是人工实际测试反馈，不是已控制初始条件的成功率统计。不要把早期仅适配器30k当成此处的第一版，也不要把14维外部力矩success_30k当成阶段A。其余模型通过`outputs/model_classification.json`清单确认，所有对照固定各自checkpoint和归一化，执行配置保持相同。

## 建议先做什么

**先用真实观测离线对照，再做执行逻辑回放，最后建立MuJoCo闭环。** 第一阶段不需要仿真画面，最能避免图像与力矩的仿真域差异影响结论。MuJoCo可以明显减少机械碰撞和逻辑错误的试错，但初始简化场景不具有真机精度和接触可靠性的保证。

### 1. 同一真实观测上的模型对照

从现有独立验证轨迹选择抓取前、闭爪前、接触治具、对准下压、就位、释放六类窗口，以相同观测/随机种子/解码次数比较两版。保留自己的归一化、状态格式、力矩维度和2秒10点历史，不把一个模型的统计量套给另一个。已确认阶段标签仍可用来选取评估片段，不需要恢复标注网页或重新标完整数据。

记录：XY/Z/姿态误差、未来10/20/50步趋势、夹爪原始输出、开爪阈值越过时刻、持续时间、再次闭爪概率、种子间波动。将抓取、放置、释放分开报告；整体动作loss和力矩loss不能代替这些指标。

现有`hover_ab_evaluation.py`支持双checkpoint、固定观测和配对噪声，但选择器只针对特定Z范围与下/停/上组，不能冒充完整抓取/释放评估。后续需要扩展事件选窗与夹爪指标，再输出对照视频、曲线和逐事件表。

使用现成入口做一个有限的下降/保持/回升对照时，可由用户另行运行：

```bash
cd /data0/wx/force-VLA
bash scripts/run.sh --gpu python -m force_vla.pi05.hover_ab_evaluation \
  --checkpoint-a outputs/pi05_force_tavla_aligned_30k_resume/checkpoint-030000 \
  --checkpoint-b outputs/pi05_stage_measured_3k/checkpoint-003000 \
  --windows outputs/force_vla_31d_windows_v3/windows.parquet \
  --output outputs/offline_lora30k_vs_stageA3k \
  --seeds 4 --per-group 2 --inference-steps 10 --device cuda:0
```

本轮没有执行此命令。输出目录须未存在；需要可用GPU显存。此比较使用阶段A对应合同的验证轨迹并检查训练集泄漏，仍不是闭环成功率。若扩展为四模型对照，要检查所有模型训练集的并集及跨根目录重复示范，不能仅凭episode编号相同/不同判断独立性。

### 2. 松爪问题先分层定位

当前smooth配置`gripper.open_trigger=0.875`、`close_trigger=0.75`、`post_close_lock_s=2.0`。阈值是动作开度比例，不是毫米；10D观测中的实测夹爪宽度与动作开度不是同一个物理量。

| 证据 | 可能问题 | 优先检查 |
| --- | --- | --- |
| 就位观测下，模型未来50步始终没有足够开爪请求 | 释放监督、阶段可观测性或动作预测问题 | 释放标签覆盖/采样、真实观测下两模型的开度输出 |
| 未来块里有开爪，但在线选中的点没有 | 动作时序/重规划截断了释放事件 | 观测时刻、块年龄、动作索引、重规划时刻 |
| 选中请求达到阈值，但命令未发送 | 闭合锁定、恢复状态、机械臂命令提交状态等阻止发送 | 命令允许条件与2秒锁定时钟 |
| 开爪命令发送，但反馈没打开 | 夹爪驱动、跟踪或物体接触问题 | 实测开度/状态、速率限制、通信和接触；不能仅凭模型曲线定因 |
| 开了又立即闭合 | 模型请求反转或缺少反转保护 | 连续开闭请求、实际开爪完成、状态转换 |

先用软件替身和可控时钟重放实际请求序列、真实推理延迟、动作索引、夹爪锁定/迟滞以及恢复状态，不连接SDK或串口。这种执行逻辑测试不需要MuJoCo。只要离线证据能确认开爪请求被锁定或跳过，就不必先冒真机碰撞风险反复测试。

既有日志里的开后再闭是全局执行风险，但没有证据表明阶段A“不松爪”必然是同一原因。先做上述分层，不能直接调低阈值或承诺重新训练会修复。

### 3. MuJoCo几何与执行仿真

先搭建Franka本体、实际Robotiq型号/指尖、工具安装变换、桌面、物料、治具和相机。运行时配置称FR3、驱动为Robotiq 2F，但夹爪具体型号/自定义指尖及治具尺寸仍需实物资料核对。

可用[MuJoCo Menagerie FR3](https://github.com/google-deepmind/mujoco_menagerie/tree/main/franka_fr3)与[Robotiq 2F-85](https://github.com/google-deepmind/mujoco_menagerie/tree/main/robotiq_2f85)作为候选资产。它们是简化模型；2F-85是否匹配实际夹爪不能由串口配置推断。FR3示例要求MuJoCo>=3.1.3，默认关节位置执行器，不等同于当前Franka笛卡尔速度控制链路。

先回放记录的TCP目标/夹爪动作，检查几何误差、轨迹净空、放置深度、夹爪开合与物体的干涉。需要笛卡尔跟踪或IK到关节控制的桥接，保留实际平滑、速率限制、动作时间推进及夹爪逻辑。不要把每步位置直接写进`qpos`后当作动态执行，这会绕过控制滞后和接触响应。

原始31D数据未存q，不能仅凭TCP姿态唯一恢复7轴冗余姿态。可以从候选初始q连续IK重建作几何诊断，但它不是实测关节运动；关节力矩比较须使用有q的日志或新增同步记录。

### 4. 最后再做视觉—力矩闭环

闭环需要每次从当前仿真状态渲染双相机RGB，构建当前10D状态、因果2秒10点力矩历史，经本地模型预测后执行，下一次观测来自执行后的仿真状态。播放真实视频并让模拟机械臂自由运动会造成观测与动作脱节，只能称开环诊断。

保持训练的相机裁剪、内外参、工具坐标、rot6d约定、动作绝对/相对定义、夹爪单位和归一化。单帧RGB模型对仿真材质、光照和物体外观敏感；若它在简化画面上失败，不能立即判定真机模型退化。

力矩尤其需要单独校准：MuJoCo执行器广义力、约束力和site力传感器均不天然等于Franka的`tau_J`、`tau_ext_hat_filtered`或TCP外部wrench。需要定义接触力分解/坐标映射、重力与惯性、工具负载、偏置、滤波和延迟，并验证无接触/重力/已知接触工况。不能直接把`qfrc_constraint`当外部关节力矩，或把`qfrc_actuator`当实测力矩来保证公平比较。

物理步长可从1–2ms量级试验，策略和观测按现有30Hz数据时间轴组织；真实推理约4Hz且异步，诊断时要重现实际耗时和旧块选择，不能让GPU算得多慢仿真都暂停然后声称解决了延迟。接触刚度/摩擦/步长要做收敛和扰动检查，步长建议不是已经验证的配置。

## 可节约哪些真机测试

离线回放最适合筛查模型的动作趋势与开爪请求；执行逻辑回放适合筛查锁定、动作索引与反转；MuJoCo适合筛查明显几何碰撞、控制参数敏感性、物体姿态扰动和流程是否跑通。

最终指标建议分开：抓取成功率、到位率、释放完成率、错误接触/超时次数；以及各阶段误差、物体滑移、控制跟踪延迟。仿真成功判据来自物体/治具真值及释放后的稳定状态，不仅是TCP到某个坐标。

MuJoCo不能复现Franka FCI通信约束错误、串口故障及未建模的柔性形变；装配摩擦/卡边与实际反射阈值也难直接等价。用小批已知真实记录校验后才解释仿真排名，最终仍保留少量标准化真机验证。不要承诺仿真筛选结果可以完全替代真机成功率。

## 当前准备情况和建议顺序

- 当前独立环境没有安装`mujoco`、`robosuite`、`dm_control`；已有`gymnasium`和PyTorch。工作区未找到可直接使用的机械臂/治具MJCF或URDF资产。仅有包名或仿真器本身不足以测试当前任务。
- 本轮只提交代码与方案，不安装仿真依赖。后续可在force-VLA内另建轻量仿真运行环境，保持现有训练/采集环境，避免为了物理引擎重建CUDA栈。
- 优先基线为旧成功LoRA30k；阶段A3k先单独定位松爪。前两阶段有结论后，再决定修执行逻辑、补释放样本，还是训练。现在不建议用更多训练步数代替诊断。
- 对新的采集/复现，补充工具与相机标定、物料/治具CAD或尺寸、q/dq、同步实际/目标位姿和开度、力矩及可用6Dwrench，能显著提高仿真与现实对照价值。
